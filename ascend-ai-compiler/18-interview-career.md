# 18 · 求职辅导与岗位方向（昇腾版）

> 原课：面试辅导 + 培养目标/职业规划。

---

## 1. 为什么单列「求职」章

企业要的不是「听过 ATC」，而是：

- 能画清编译器地图并落到昇腾名词  
- 能独力排通转换/精度/性能三类问题  
- 有一个可讲的 CV 或 LLM 项目（Lab5/6）

本章把大纲能力目标收成 **可自检清单 + 题库方向**。

---

## 2. 岗位与「为什么招你」

| 岗位 | 核心证明点 | 本课对应 |
|---|---|---|
| AI 编译器 | IR、Pass/图优化、算子适配 | 01–04, 07–10 |
| 边缘部署 | om、预处理后处理、流水 | 06, 14–15 Labs |
| 模型优化 | 量化、校准、混合精度、profiling | 11–13 |
| 芯片应用支持 | 适配、版本矩阵、精度定位 | 06, 08, 18 |

---

## 3. 培养目标自检（效果）

- [ ] Frontend/Backend + 昇腾落点能画  
- [ ] ONNX→om→推理独立完成  
- [ ] 做过 PTQ 与回退  
- [ ] 会用 profiling 讲清瓶颈  
- [ ] Lab5 或 Lab6 可演示  
- [ ] 有可交付的部署/性能记录  

---

## 4. 面试题方向（怎样准备）

每题用「为什么→怎么做→效果」答，与讲义风格一致：

1. Graph 优化 vs Kernel 优化各一例  
2. 融合为何省带宽（接存储层次）  
3. 对称/非对称；per-channel  
4. ATC 五步；om 里有什么  
5. Prefill/Decode；KV 为何涨  
6. 精度掉了排查顺序  
7. `dyn_cast` vs `cast`；SmallVector 为何存在  
8. AOE 何时做、先子图还是先算子  

---

## 5. 职业发展（大纲）

技术专家 / 项目经理 / 架构 / 管理 / 创业——共通底座仍是：**能把模型稳定、高效地送到芯片上**。平台用昇腾证明即可。

---
