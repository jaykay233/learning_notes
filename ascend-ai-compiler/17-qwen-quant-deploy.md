# 17 · Qwen 模型量化与昇腾部署

> 原课：Qwen3 的 W8A8 / W4A16 等方案。

---

## 1. 为什么 LLM 量化选项和 CV 不完全一样

| | CV | LLM |
|---|---|---|
| 校准数据 | 图 | **文本** |
| 指标 | Top-1/mAP | 困惑度、业务集、盲测 |
| 形状 | 相对固定 | decode **变长 + KV** |
| 敏感点 | 检测头等 | 嵌入、部分投影、lm_head… |

所以 [11](./11-int8-quant-math.md)/[12](./12-calibration.md) 的数学仍适用，但 **工程清单不同**。

---

## 2. W8A8 vs W4A16（怎样选）

| 方案 | 含义 | 为什么选它 | 风险 |
|---|---|---|---|
| W8A8 | 权重+激活 8bit | 冲吞吐、激活也压带宽 | 精度更易掉 |
| W8A16 | 权 8 激 16 | 折中 | 激活带宽仍高 |
| W4A16 | 权 4 激 16 | 权重占内存为主时 | 权太狠需好校准/混合 |

**混合精度：** 敏感层回退——Lab4 思维搬到 LLM。

---

## 3. 部署步骤（端到端）

```text
1. 选定推理栈（引擎 / 是否 ONNX / 专用导出）
2. 量化 + 文本校准集
3. 转到昇腾可执行格式
4. 接上 KV Cache + 采样循环（prefill/decode）
5. 测 TTFT、tok/s、精度门禁
```

与架构笔记交叉：`models/qwen-3.8/`、`qwen3.8-flash-next/`（结构决定哪些层值得融、值得保）。
